What this version changes from d11_hud
- Everything named d11_ is now whip_ (resource whip_hud, convar whip_locale, command whip_seatbelt, etc.).
- /hud menu: drag and resize every part of the HUD, and keep health, armour, energy, food, water and stress on screen.
- whip_theme: a WHIP theme that carries the HUD layer and replaces WHIP's old gauges, rev dial and minimap.
- whip_hud takes the active WHIP theme over from the old whip_theme_d12.
- WHIP's voice bars moved to the bottom-right corner.
- The compass sits top middle, as in the original GTA VI layout.
